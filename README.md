## Trabajo 01: Optimización heurística

### Punto 1

La implementación de los algoritmos se puede encontrar en `Trabajo 01/Optimización numérica`, de forma que se recomienda ubicarse en este directorio y usar un entorno virtual de Python. Para lograr esto en bash:

```
cd "Trabajo 01\Optimización numérica"

# Crear venv
python -m venv .venv

# Instalar librerías y activar venv
.venv/Scripts/python -m pip install -r requirements.txt
source .venv/Scripts/activate
```
